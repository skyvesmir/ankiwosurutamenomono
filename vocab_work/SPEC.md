# VocaForge 単語データ 例文生成・補足整形 仕様書

## ゴール
入力の英単語データ（6553語）に対し、**品詞ごとの例文（英文＋日本語訳）**を新規生成し、
既存の**補足（note）の文体を整える**。最終的に1本のCSV（UTF-8, BOMなし）として出力する。

## 入力
`vocab_clean.json` … 配列。各要素:
```
{ "no": "1", "word": "agree", "ipa": "/əˈɡriː/", "pos": "動詞",
  "meaning": "同意する、賛成する、意見が一致する", "note": "…" }
```
- `pos`（品詞）は日本語の読点「、」区切り（例: `名詞、動詞`）。
- `meaning` が複数品詞のとき `【名】…<br>【動】…` の形式。
- `ipa` に「/…/ (名詞)<br>/…/ (動詞)」のように複数併記の語がある（heteronym）。保持する。

## 出力CSV（列順を厳守）
`番号,単語,発音記号,品詞,意味,補足,例文,例文訳`
- 番号・単語・発音記号・品詞・意味 は入力のまま（原則変更しない。明らかな誤りのみ修正）。
- **補足**: 文体を整える（下記ルール）。
- **例文**: 品詞ごとに1文。**英文のみ**。
- **例文訳**: 例文に対応する自然な日本語訳。

## 例文のルール（最重要）
1. **品詞ごとに例文を作る。** 複数品詞の語は、例文・例文訳とも `<br>` で区切り、
   各文の先頭に意味欄と同じ品詞マーカー（`【名】`『【動】』『【形】』等）を付ける。
   - 品詞マーカーは意味欄(meaning)の順序・表記に一致させること。
   - 例（tip, 名詞・動詞）:
     - 例文: `【名】"Here is a tip," ... <br>【動】He tipped his chair ...`
     - 例文訳: `【名】「一つ秘訣を」… <br>【動】彼は椅子を …`
2. **単一品詞の語は品詞マーカーを付けない**（例文・例文訳とも素の1文）。
3. **トーン**: 基本は**ユーモラス**（クスッと笑える、意外なオチ、あるある系、皮肉）。
   - 全体の **1〜2割** に「**ドスの効いた**」例文を混ぜる（脅し・凄み・ブラックユーモア）。
     例: `Don't blame the dog. We both know who really ate the cake, and I am watching you.`
   - 下品・差別・過度な暴力・政治的にセンシティブな内容は避ける。学習者が読める範囲。
4. **英文の質**: 文法的に正確。対象単語をその品詞で自然に使う。中〜上級学習者向けの実用的な文。
   1文（またはセミコロン/カンマで繋いだ1つの文）に収める。長すぎない（目安 8〜22語）。
5. **和訳**: 直訳でなく自然な日本語。オチ・皮肉のニュアンスを保つ。
6. 例文中で対象語は基本その語形（活用可）で登場させる。

## 補足（note）の整形ルール
- 事実（語法・語源・注意点）は**変えない**。文体だけ統一する。
- **常体・体言止めの混在をならし、基本「です・ます」調に統一**。
- 文末に句点「。」。冗長な重複を削る。誤字・表記ゆれを直す。
- 英単語・記号の前後は半角スペースで読みやすく（例: `agree with 人`）。
- 明らかな内容の誤りがあれば正す（英語知識ベースでの判断可）。必要なら簡潔に補足を足す。

## データ整合（すでに実施済み。以降も維持）
- 重複語は統合済み、`kindle` の列ずれ修正済み。番号は1..6553で振り直し済み。
- 番号は最終出力でも 1..6553 の連番を維持する。

## 品質チェック（生成後に必ず実行）
`check.py` を通す:
- 全行が8列であること（csvパースで列崩れゼロ）。
- 品詞数（読点区切り）== 例文の`<br>`+1 == 例文訳の`<br>`+1（複数品詞語）。
- 例文・例文訳が空でない。
- 番号が1..6553連番。
CSVは `csv.writer`（QUOTE_MINIMAL）で書き、カンマや改行を含むフィールドを正しくクォートすること。
（例文にカンマが多いので、手書き連結は禁止。必ず csv.writer を使う。）
