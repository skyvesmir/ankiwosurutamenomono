# ✯ ANKISHIYOUZE (暗記しようぜ) ✯

「好きなものを、好きなだけ、楽しく効率よく暗記する」ためのWebアプリケーションポータルサイトです。
日常生活から受験勉強、さらにはユニークなファンタジー言語まで、幅広い分野の暗記を徹底サポートします。

## 🌟 提供中の暗記コース一覧

現在、以下の個性豊かな暗記コースが稼働しています。

### 1. 🔮 魔女文字暗記コース (`魔女文字暗記.html`)
- **概要**: 『魔法少女まどか☆マギカ』の劇中に登場するあの「魔女文字（ルーン文字）」を解読・暗記するためのコースです。
- **特徴**: ビジュアルと連動して、不思議なルーンの世界に浸りながら文字をマスターできます。

### 2. ⚡ VocaForge 英語語彙コース (`/vocaforge/`)
- **概要**: 忘却曲線理論（FSRSアルゴリズム）に基づいた、英語語彙の超強化トレーナーです。
- **特徴**: 
  - 単語の定着度に応じた最適な出題間隔の自動スケジューリング。
  - 語源（Etymology）や実用フレーズと結びつけた多角的な学習。
  - Supabase連携による、進捗データのクラウド同期対応。

### 3. 📝 例文暗唱コース (`英語例文暗唱.html`)
- **概要**: 学校の定期テスト対策用に作成した、英語例文の暗唱シートです。
- **特徴**: 身内の定期テストに特化した内容なので、基本的には作成者と同じ学校の特定の人だけが得するローカルなツールです。

### 4. ⚖️ 公共＋政経暗記コース (`公共暗記.html`)
- **概要**: 「公共」および「政治・経済」の基本用語、現代社会の仕組みをスピード暗記するコースです。
- **特徴**: テストや資格、社会人の一般常識としても役立つ重要トピックを網羅。

### 5. 🌸 古典暗記コース「いとをかし」 (`いとをかし.html`)
- **概要**: 古文単語や古典文法、文学史などの知識を雅（みやび）に覚えるためのコースです。
- **特徴**: 趣のあるデザインの中で、日本の美しい古典文学の世界を感じながら学べます。

### 6. ⚛️ 物理記号暗記コース (`物理暗記.html`)
- **概要**: 物理学で頻出する各種記号（$\rho$, $\lambda$, $\omega$ など）や基本公式の意味をサクッと整理するコースです。
- **特徴**: 理系受験生や科学ファン必見！ややこしいギリシャ文字や物理定数と一瞬で友達になれます。
